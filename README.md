# 🎵 Calm-Concert

A serene web application designed to provide peaceful music and relaxation experiences.

## 📋 Overview

Calm-Concert is a minimalist web application that combines calming music with a tranquil user interface. Perfect for those looking to unwind, meditate, or focus while working.

## ✨ Features

- 🎶 Soothing background music
- 🎨 Clean and intuitive user interface
- 📱 Responsive design for all devices
- ⚡ Lightweight and fast-loading
- 🌙 Peaceful aesthetic

## 🚀 Getting Started

### Prerequisites
- A modern web browser (Chrome, Firefox, Safari, Edge)
- Internet connection

### Installation

1. Clone the repository:
```bash
git clone https://github.com/FariNoveri/Calm-Concert.git
```

2. Navigate to the project directory:
```bash
cd Calm-Concert
```

3. Open `web.html` in your web browser

That's it! No installation or dependencies required.

## 📖 Usage

Simply open the `web.html` file in your web browser to start enjoying a calm and peaceful experience. The application will automatically load with soothing content.

## 🛠️ Technologies

- Web Audio API
